How it works

One loop that always keeps a path forward.

Notice → Route → Act

One-tap capture with auto-GPS and a photo. An AI classifies it and suggests the smallest action that can actually resolve it.

The care loop closes

Report → handling → verified fix → story.

A neighbour confirms the repair, the loop closes, and the resolution gets told — so effort turns into visible, shared progress.
