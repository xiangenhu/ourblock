How it works

Notice → Route → Act — a single loop that always keeps a path forward.

👀 Notice

One-tap capture with auto-GPS, a photo or a short video — evidence-rich, situated awareness of the block you live on.

🧭 Route

An AI classifies each observation and suggests the lowest viable rung of action, so every issue keeps a concrete next step.

🌱 Act

Tend it yourself, rally neighbours, or send a report to the city — then watch the care loop close and the story get told.

The Good ✦

Capitalization & savoring — celebrate what neighbours are doing well. The Good stream never escalates to the city; it stays a positive, savouring space.

Needs Care △

Critical awareness — notice what needs attention, then act. Care items move through a visible loop: report → handling → verified fix → resolution story.

01Theory

A psychological-empowerment intervention disguised as a neighbourhood app — each interface element maps to a named idea.

Psychological empowerment

The empowerment tradition splits agency into intrapersonal (self-efficacy), interactional (understanding your community), and behavioural (taking action) components. Our Block gives each a surface: a personal impact view, a location-scoped feed, and one-tap capture.

Learned hopefulness

The inverse of learned helplessness: agency grows when action reliably produces an effect. The action ladder guarantees every observation keeps a path forward, so no issue becomes a dead end.

Capitalization & savoring

Positive-psychology work on savouring the good builds social capital. The Good stream is a dedicated, non-escalating space to notice and celebrate — it deliberately cannot be sent to the city.

Collective efficacy & subsidiarity

Neighbourhoods act when they believe shared action works, and problems are best handled at the lowest capable level. "Our block this month" surfaces the collective; the router always tries the smallest rung first.

02Technology

Lightweight, privacy-conscious, cloud-native — three invariants hold the design together.

Node.js + Express · ESM, no build Vanilla-JS SPA · no framework Google Cloud Storage · sole persistence Single LLM gateway · 6 vendors JWT cookie auth · OAuth + SMTP gateway Hybrid maps · Google · 高德 · Leaflet Hash-based i18n · 17 languages xAPI analytics · LRS Cloud Run · single container

🗄️ GCS is the only store

No SQL, no local disk. The data model is the object-key layout; each post doc is self-contained, so listing the feed is one prefix scan. Concurrent writes use compare-and-set via GCS generation preconditions.

🚪 One LLM gateway

Every model call flows through a single chokepoint that owns vendor choice, request shape, language enforcement and token accounting. Adding a vendor is one config entry — features never call a provider directly.

🌗 Graceful degradation

With zero AI configured, routing falls back to a transparent keyword heuristic and composition to templates — the app is fully functional with no keys, and never depends on any single provider.

Six runtime dependencies, zero build steps, and roles derived server-side (never client-asserted). Media never touches local disk — uploads land in GCS and stream back through the media route.

03Applications

Where it fits and who it serves.

🏘️ Neighbourhoods & resident associations

The core case: residents of a block notice, savour and repair their shared space, with a light steward tier (an email allowlist) for community moderation.

🏛️ Municipal & 311-style intake

The send-to-city rung drafts a structured, geo-located, evidence-rich report for the responsible agency — but only after the lower rungs have been offered.

🎓 Civic education & learning analytics

xAPI statements to a learning-record store make civic participation legible as learning, so classrooms and programs can run place-based projects on it.

🌏 Multilingual & cross-border communities

Hash-based i18n back-fills 17 languages (including four right-to-left) automatically through the gateway, and maps switch between Google, 高德 and self-hosted Leaflet by region.

04Impacts

What changes for each audience — framed as mechanisms the design produces, not measured outcomes.

For residents

Because every observation keeps a viable next step, the loop is built to convert noticing into agency instead of frustration — and a savouring stream to make the good visible, not just the broken.

For neighbourhoods

A location-scoped feed plus "our block this month" is designed to surface collective efficacy — the shared sense that acting together works — rather than isolated individual complaints.

For cities

Escalation only happens when lower rungs can't resolve an issue, so what reaches the agency is structured, situated and pre-triaged — by design, less noise per report.

For educators & stewards

xAPI instrumentation turns real civic participation into analyzable learning signals, so a steward or teacher can see engagement as it happens instead of after the fact.
