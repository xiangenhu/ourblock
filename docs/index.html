How the interface maps to the empowerment model

Each numbered marker on the mockups ties a concrete UI element to a mechanism from the prior discussion, so the design can be reviewed against theory rather than taste.

1
One-tap captureBehavioral component. Lowering friction to act is what converts critical awareness into participation.
2
Photo + short video (≤15s) + auto-GPSEvidence-rich awareness. Rich, situated media makes the observation credible and actionable; location is captured automatically on phone.
3
Two streams: Good ✦ / Needs Care △Capitalization vs. critical awareness. The good stream is a savoring intervention; the care stream builds the cognitive map of the environment.
4
Location-sensitive feedSituated efficacy. "Within 1.2 km" anchors empowerment to the place the resident can actually affect.
5
AI action-ladder suggestionLearned hopefulness. Routing each issue to fix-it-yourself / rally-neighbours / send-to-city keeps problems coupled to a path to act.
6
"My impact" + "Our block this month"Intrapersonal self-efficacy + collective efficacy (Sampson et al., 1997). Loop-closing turns effort into visible, attributable change.
